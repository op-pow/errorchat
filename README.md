# Nexus Chat

A modern, single-page chat application interface built with HTML5, Tailwind CSS, and vanilla JavaScript. This application demonstrates a clean, responsive UI for real-time messaging simulations.

## Features

- **Responsive Design**: Works on mobile and desktop.
- **Real-time Simulation**: Message sending with simulated bot responses.
- **Auto-scroll**: The chat window automatically scrolls to the latest message.
- **Interactive UI**: Hover effects, input focus states, and dynamic message bubbles.

## Getting Started

1. Download the `index.html` file.
2. Open it in any modern web browser.
3. Type a message in the input field and press Enter or click the send icon.

## Technologies Used

- HTML5
- Tailwind CSS (via CDN)
- Vanilla JavaScript
