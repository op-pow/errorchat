Nexus Chat has been upgraded to a multi-contact platform. You can now switch between 'Nexus AI' and simulated 'Real People' contacts from a new sidebar. Each contact maintains its own message history and interaction logic. 

Features:
- Contact Sidebar with online status indicators.
- Dedicated AI Profile for assistance.
- Simulated 'Real People' profiles with human-like messaging delays.
- State management for switching between different conversations.
- Responsive layout designed for desktop and mobile use.
